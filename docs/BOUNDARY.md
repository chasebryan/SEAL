# Boundary

SEAL-Core v0 is a terminal-native normative authority core for sealed evidence, capability-bound authority, and fail-closed system design.

The exact v0 claim boundary is limited to the F* authority model in `src/` and successful verification of that model with F*.

SEAL-Core v0:

- runs as a terminal-native source-level prototype
- does not provide kernel isolation
- is not an operating system
- is not seL4
- is not seL4-equivalent
- is not production authorized
- is not externally certified
- is not government approved
- is not formally verified as a whole system

No operational deployment authority is implied by this repository.
