# Language Policy

F*/Low* is the preferred trusted-core language.

C is allowed only as generated extraction output or future ABI membrane.

C extraction is deferred until a compatible KaRaMeL toolchain is pinned.

Handwritten C is not allowed in v0.

Rust is not part of v0.

Python and shell must not contain authority logic.

No security policy may live only in Makefile or shell scripts.
