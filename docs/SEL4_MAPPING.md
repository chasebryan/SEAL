# seL4 Mapping

This mapping is conceptual only in v0.

Future conceptual correspondences:

- SEAL subject -> future protection domain / component identity
- SEAL capability -> future seL4/capDL authority concept
- SEAL gate -> future authority decision component
- SEAL receipt -> future measured transition object
- SEAL evidence -> future measured state input

SEAL-Core v0 does not integrate seL4, does not provide kernel isolation, and is not seL4-equivalent.
